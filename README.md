# 🌌 Constellar — 3D Scroll Portfolio

A cinematic, scroll-driven 3D interactive portfolio website built for **Shubhra AR Hebbar** (AI/ML & Full-Stack Engineer).

The application features a 3D neural network constellation in deep space — nodes light up and connect as the user scrolls, visually representing skills, experience, projects, and leadership achievements.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **3D Graphics**: Three.js + React Three Fiber (`@react-three/fiber`) + React Three Drei (`@react-three/drei`)
- **Post-processing**: `@react-three/postprocessing` (Bloom, Vignette, Chromatic Aberration)
- **Animation & Camera Path**: GSAP + `ScrollTrigger`
- **Smooth Inertial Scrolling**: Lenis (`lenis`)
- **UI & Motion**: Tailwind CSS + Framer Motion (`framer-motion`) + Lucide Icons (`lucide-react`)

---

## ✨ Features

- **3D Deep Space Neural Network**: Interactive glowing icosahedra, orbital rings, and Fibonacci sphere skill node distributions.
- **Traveling Signal Dots**: Emissive energy dots moving along neural connections across sections.
- **Lenis Inertial Scroll & GSAP Camera Rig**: Smooth 12-keyframe camera spline journey flying through the 3D space.
- **Interactive UI Cards**: Glassmorphism overlays with live typewriter roles, skill filters, and capability radar metrics.
- **Accessibility & Modes**: Instant 2D/3D mode toggle and sound toggle.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/ShubhraAR-Hebbar/Constellar.git

# Navigate to the project directory
cd Constellar

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Build for Production

```bash
npm run build
```
